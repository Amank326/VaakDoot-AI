## 🇮🇳 What is VaakDoot AI?

<table>
<tr>
<td width="60%">

**VaakDoot AI** is India's most advanced, cinematic AI-powered **Election Education Platform** — built for the 900 million+ eligible voters who deserve clear, accessible, and beautiful access to democratic knowledge.

Built as a **single-file SPA** with zero build tools, zero frameworks, and zero compromises on design quality. Every pixel, every animation, and every AI response is engineered to make democracy feel alive.

**The Problem:** Millions of first-time and rural Indian voters lack clear, accessible information about how elections work — in their own language.

**The Solution:** An always-on, voice-enabled, bilingual AI tutor that breaks down India's entire election process with stunning visuals, interactive quizzes, real-time AI answers, and live polling booth maps.

## 🏗️ Architecture

```
VaakDoot-AI/
├── files/
│   ├── index.html                        ← Standalone demo (root)
│   └── vaakdoot-ai-final/
│       └── vaakdoot-3d/
│           ├── index.html                ← Complete Single-File SPA ⭐
│           └── README.md                 ← Project-level docs
├── README.md                             ← You are here
└── LICENSE
```

**Why single-file?**

```
✅  Zero build tools — open in browser, done
✅  Instant deploy to GitHub Pages / Netlify / Vercel
✅  < 10 MB total — no bloat
✅  Works offline after first load (except AI + Maps)
✅  No node_modules, no webpack, no babel
```

## 🔧 Quick Start

### Prerequisites

| Tool | Where to Get |
|---|---|
| **Gemini API Key** | [aistudio.google.com](https://aistudio.google.com/app/apikey) — Free tier available |
| **Google Maps Key** | [console.cloud.google.com](https://console.cloud.google.com/) |
| **Browser** | Chrome / Edge (for best Web Speech API support) |

### Step 1 — Clone

```bash
git clone https://github.com/Amank326/VaakDoot-AI.git
cd VaakDoot-AI/files/vaakdoot-ai-final/vaakdoot-3d
```

### Step 2 — Configure API Keys

Open `index.html` and replace the placeholder values:

```javascript
// Line ~2500 in the <script> section
const GK = 'YOUR_GEMINI_API_KEY_HERE';
```

```html
<!-- Maps script tag near bottom of <body> -->
<script src="https://maps.googleapis.com/maps/api/js?key=YOUR_MAPS_KEY&callback=initMap" async defer></script>
```

### Step 3 — Run Locally

```bash
# Option A — Python (recommended)
python3 -m http.server 8000
# Open: http://localhost:8000

# Option B — Node.js
npx serve .
# Open: http://localhost:3000

# Option C — Just drag index.html into Chrome
# (Maps + Voice work best with a proper server origin)
```

### Step 4 — Deploy to GitHub Pages

```bash
# In your forked repo:
# Settings → Pages → Source: Deploy from branch → Branch: main → /root
# Your live URL: https://YOUR_USERNAME.github.io/VaakDoot-AI/files/vaakdoot-ai-final/vaakdoot-3d/
```
